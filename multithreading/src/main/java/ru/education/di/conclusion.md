### Общий алгоритм
1. имеем основной класс с двумя контейнерами мапами: мапа с созданными бинами  и мапа с зарегистрированным отсканированными классами
2. сканируем пакеты на предмет нужных аннотаций и кладем в мапу с зареганными классами
3. при запросе бина getBean('') ищется класс в мапе с зареганными классами, если не находим то Exception. 
4. нашли бин, через рефлекшен проанализировали его конструктор. Если там есть параметры, то выполняем внедрение зависимости 
5. внедрение зависимости. Если бин не найден, то создадим (если его класс зареган в мапе).
6. далее через рефлекшен сеттим в поле наш бин

### Архитектура
```java
Container
   ↓
scan("package") → находит @Component
   ↓
getBean("name") → создаёт экземпляр
   ↓
@Autowired → внедряет зависимости (рефлексия)
   ↓
возвращает готовый объект
```

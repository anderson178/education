### Bubble Sort (Сортировка пузырьком)

Проходит по массиву, сравнивает соседние элементы и меняет их местами, если левый больше правого.
Повторяет, пока массив не отсортируется.

Время: O(n²) — в худшем и среднем.

### Selection Sort (Сортировка выбором)

Находит минимальный элемент в неотсортированной части и ставит его в начало. Повторяет для оставшейся части.

Время: O(n²) — всегда.

### Insertion Sort (Сортировка вставками)

Строит отсортированную часть слева. Каждый новый элемент вставляется на своё место, как в картах.

Время:
1. Худшее: O(n²)
2. Лучшее: O(n) — если массив почти отсортирован

### Merge Sort (Сортировка слиянием)

1. Делит массив на две части.
2. Рекурсивно сортирует каждую.
3. Сливает две отсортированных части в одну.

Слияние (merge):два указателя бегут по левой и правой части, выбирают меньший — и так заполняют результат.

Время: O(n log n) — гарантированно, всегда.

### Quick Sort (Быстрая сортировка)

1. Выбирает опорный элемент (pivot).
2. Перемещает все элементы меньше pivot — влево, больше — вправо (разделение).
3. Рекурсивно сортирует левую и правую части.

Выбор pivot:
1. Первый/последний элемент — просто, но плохо на отсортированном массиве.
2. Случайный — лучше.
3. "Медиана трёх" — из начала, середины, конца.

Время:
1. Среднее: O(n log n)
2. Худшее: O(n²) — если pivot всегда минимальный/максимальный

### Radix Sort (Поразрядная сортировка)

1. Не использует сравнение!
2. Сортирует числа по каждому разряду (с младшего к старшему), используя устойчивую сортировку (обычно Counting Sort).

```java
Пример:
[170, 45, 75, 90, 2, 802, 24]
→ Сортируем по единицам → десяткам → сотням.
```
Время: 
1. O(n × k), где k — количество разрядов (цифр)
2. Для 32-битных чисел: k ≈ 10 (в десятичной) или 32 (в двоичной)

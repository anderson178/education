### Общие сведения
Платформа потоковой обработки, подходит для больших данных, stream processing, с долгим хранением и возможностью перечитывания

### Как работает:
- Один сервис говорит:
- "Произошло событие: 'Пользователь сделал заказ'" — и записывает это в ленту событий.
- Kafka сохраняет это сообщение (как запись на плёнку).
- Много сервисов могут слушать эту ленту:
- Один — отправляет письмо.
- Другой — записывает в базу.
- Третий — считает аналитику.
- И каждый может начать слушать с любого места:
- С сегодняшнего утра.
- С вчерашнего дня.
 - С самого начала.

✅ Одно событие — может быть обработано многими, и даже несколько раз. 

### Когда использовать
- Аналитика в реальном времени
- Нужно, чтобы 3 сервиса узнали о заказе
- Хочу перезапустить сервис и обработать старые события
- Аудит, лог событий

### Общие сведения
Это классический брокер сообщений, лучше подходит для асинхронных задач, с гибкой маршрутизацией и подтверждением доставки.

### Как работает:
- Один сервис говорит:
- "Я сделал заказ. Отправь это сообщение в очередь 'Обработать заказ'".
- RabbitMQ кладёт это сообщение в очередь (как в ящик).
- Другой сервис (например, "Сервис уведомлений") забирает сообщение из очереди и обрабатывает.
- Как только он сказал: "Я сделал!" — сообщение исчезает из очереди.


### Когда использовать
- Отправка email
- Обработка платежей
- Надёжная доставка
- Задачи (jobs)

### Виды:
1. SonarQube — для общего анализа качества, дублирования, покрытия, безопасность
   
Проверяет:
- Баги (bugs)
- Уязвимости (vulnerabilities)
- Запахи кода (code smells)
- Покрытие тестами
- Дублирование кода

2. Checkstyle — чтобы соблюдать единый стиль кода в команде

Проверяет:
- Именование переменных (camelCase)
- Длина строк
- Отступы
- Расположение фигурных скобок
- Javadoc
 
3. SpotBugs — находит реальные баги, например, NullPointerException. Анализирует байт-код а не исходники

Находит реальные баги:
- NullPointerException
- Бесконечные рекурсии
- Неправильная синхронизация
- Утечки памяти

4. PMD — помогает избавиться от плохих практик

Проверяет:
- Неиспользуемые переменные/импорты
- Пустые блоки catch
- Избыточные условия
- Неправильное управление ресурсами
- Сложность методов (cyclomatic complexity)

5. ErrorProne — особенно полезен, так как ловит ошибки ещё на этапе компиляции.Интегрируется в компилятор javac, ловит ошибки на этапе компиляции. Предотвращение багов до сборки
